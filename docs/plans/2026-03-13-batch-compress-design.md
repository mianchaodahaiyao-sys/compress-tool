# 批量压缩工具 设计文档

日期：2026-03-13

## 概述

一个基于 Electron + FFmpeg 的本地批量压缩工具，支持图片和视频混合批量压缩，可设置专业压缩参数，输出文件与原文件同目录。

## 技术栈

- **框架**：Electron
- **压缩引擎**：FFmpeg（`C:\Users\JD\Desktop\ffmpeg\bin\ffmpeg.exe`）
- **前端**：HTML + CSS + 原生 JS（Electron 渲染进程）
- **后端**：Node.js（Electron 主进程，负责调用 FFmpeg 子进程）

## 参数规则

### 图片
- 参数：`-q:v <value>`
- 范围：1–31（1=最高质量，31=最大压缩）
- 默认：**12**
- 支持格式：jpg、jpeg、png、webp、bmp

### 视频
- 参数：`-b:v <value>k`
- 默认：**1024k**
- 支持格式：mp4、mov、avi、mkv、flv、wmv

## 输出规则

- 输出文件与原文件同目录
- 命名：`原文件名_压缩.扩展名`
- 示例：`photo.jpg` → `photo_压缩.jpg`

## 状态显示

每行文件显示：文件名 / 类型 / 状态

- 等待中
- 压缩中...（显示百分比，通过解析 FFmpeg stderr 输出）
- 完成（显示原始大小 → 压缩后大小）
- 失败（红色，悬停显示错误信息）

## 操作控制

- 开始压缩：逐个顺序处理，不并行
- 暂停/继续：暂停当前任务队列
- 取消：终止当前 FFmpeg 进程并清空队列
